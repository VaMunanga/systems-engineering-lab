## What I learned?

- why we dont put all our code in one layer or one program - to ensure that we easily find,refactor and debug code.
- single responsibilty principle its importance- to ensure that code is easily found,changed,debugged.
- the four layers of coding service layer,repository layer,controller layer.
- The control layer is the one that handles teh http requests, validates them, calls the respective service and return responses
- the service layer is where all the business logic and policies as well as rules are largely applied(no api,no http)
- the repository layer- largely interacts with the datbase sometimes called the data layer
- the infrastructure layer - this talks to other outside systems that interact with our project.(meta,supabase,redis,email,payment,storage)
- The mental model that should be employed in understanding architecture is viewing software as an organisation each department has a responsibility
